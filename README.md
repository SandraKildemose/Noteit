# Noteit

Noteit er et sideprojekt med fokus paa noteskrivning til STEM-fag. Projektet er bygget som en digital notesbog til studiebrug, hvor noter, fagligt materiale og struktur kan samles i en mere overskuelig arbejdsgang.

Projektet bruges i dag i forbindelse med mit studie og er udviklet lokalt frem til en faerdig version, som jeg derfor laegger op her som samlet produkt og kildekode.

## Min arbejdsproces

Jeg har arbejdet lokalt med produktet og gennemset koden, inden jeg lagde det op. Undervejs har jeg brugt prompts som sparring til ideer, struktur, debug og forbedringer, men jeg har ogsaa selv arbejdet direkte med koden, funktionerne og designet.

En vigtig del af projektet har vaeret arbejdet med en mere sikker databaseopsætning. Projektet indeholder Supabase-relaterede filer med fokus paa login, brugerdata, delte noter og row-level security, saa data kun kan tilgaas af de rigtige brugere.

## Indhold

- Webapp til noter og studiearbejde
- STEM-orienterede funktioner og struktur
- Supabase database-schema og konfigurationsskabelon
- Deployment-noter til videre hosting
- Lokal kildekode fra den nyeste projektversion

## Status

Dette repository er lagt op som et faerdigt lokalt produkt. Det viser baade det praktiske produkt og processen bag: promptet sparring, egen kode, gennemgang, debug og arbejde med databaser.
